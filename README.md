# 12 Anh Hùng Amphoreus

Trang web triển lãm giới thiệu 12 Á Thần của thế giới Amphoreus trong game **Honkai: Star Rail**. Đây là dự án fan-made, được làm cho mục đích học tập.

🔗 **Xem trang web:** https://dangdihnlam.github.io/A3/

## Giới thiệu

Mỗi nhân vật được trình bày dưới dạng một thẻ gồm ảnh, tên và danh hiệu Á Thần. Trang có hiệu ứng khi di chuột và hiển thị tốt trên cả máy tính lẫn điện thoại.

## Công nghệ sử dụng

- HTML5
- CSS3 (Grid, Flexbox, animation, media query)
- GitHub Pages để đưa trang lên mạng

## Cấu trúc thư mục

```
A3/
├── index.html      # Nội dung trang
├── style.css       # Giao diện
├── images/         # Ảnh 12 nhân vật
└── README.md
```

## Chạy trên máy

```bash
git clone https://github.com/dangdihnlam/A3.git
cd A3
```

Sau đó mở file `index.html` bằng trình duyệt.
